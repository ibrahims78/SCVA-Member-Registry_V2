## 1. إعداد ملف البيانات — Google Sheets

### 1.1 إنشاء الجدول

1. اذهب إلى [sheets.google.com](https://sheets.google.com)
2. اضغط **"+"** → جدول بيانات فارغ
3. غيّر الاسم إلى: **"سجل الطلبات — [اسم جهتك]"**

### 1.2 أعمدة الجدول (12 عمود عربي)

أضف العناوين التالية في الصف الأول (A1 حتى L1):

| الخلية | أدخل هذا النص |
|--------|-------------|
| A1 | رقم الطلب |
| B1 | تاريخ الإرسال |
| C1 | وقت الإرسال |
| D1 | الاسم الكامل |
| E1 | رقم الهاتف |
| F1 | البريد الإلكتروني |
| G1 | المدينة / المنطقة |
| H1 | نوع الطلب |
| I1 | تفاصيل الطلب |
| J1 | الحالة |
| K1 | ملاحظات المسؤول |
| L1 | تاريخ آخر تحديث |

### 1.3 تنسيق صف العناوين

1. حدّد الصف الأول بالكامل (اضغط على رقم "1")
2. **لون الخلفية:** أزرق داكن `#1565C0`
3. **لون النص:** أبيض
4. **الخط:** عريض (Bold)
5. **تثبيت الصف:** عرض → تجميد → صف واحد
6. **تفعيل الفلتر:** بيانات → إنشاء فلتر

### 1.4 قائمة منسدلة لعمود H (نوع الطلب)

1. حدّد العمود H كاملاً (اضغط على حرف H)
2. بيانات → التحقق من صحة البيانات
3. المعيار: **قائمة من العناصر**
4. أدخل: `طلب معلومات,طلب خدمة,شكوى,اقتراح,طلب دعم فني,أخرى`

### 1.5 قائمة منسدلة لعمود J (الحالة)

1. حدّد العمود J كاملاً
2. بيانات → التحقق من صحة البيانات
3. أدخل: `جديد,قيد المعالجة,يحتاج معلومات إضافية,مكتمل,مرفوض`

### 1.6 تنسيق شرطي للحالة (اختياري لكن احترافي)

أضف تنسيقاً شرطياً على عمود J:
- **جديد** → خلفية برتقالية فاتحة `#FFE0B2`
- **قيد المعالجة** → خلفية زرقاء فاتحة `#E3F2FD`
- **مكتمل** → خلفية خضراء فاتحة `#E8F5E9`
- **مرفوض** → خلفية حمراء فاتحة `#FFEBEE`
- **يحتاج معلومات إضافية** → خلفية صفراء فاتحة `#FFFDE7`

### 1.7 احفظ معرّف الجدول

من رابط الجدول:
```
https://docs.google.com/spreadsheets/d/[SPREADSHEET_ID]/edit
                                        ^^^^^^^^^^^^^^^^
                                        انسخ هذا الجزء
```
**احفظه** — ستحتاجه في خطوة إعداد Apps Script.

### 2.1 Code.gs — الكود الرئيسي

انسخ والصق هذا الكود **بالكامل** في ملف `Code.gs`:

```javascript
// ====================================================
// Code.gs — الكود الرئيسي لنظام نموذج الطلبات
// ====================================================

// ─── الإعدادات الرئيسية ──────────────────────────────
// ⚠️ استبدل القيم الثلاث التالية بمعلوماتك:
const CONFIG = {
  SPREADSHEET_ID : 'ضع_هنا_معرّف_جدولك',    // ← من رابط الجدول (القسم 1.7)
  SHEET_NAME     : 'سجل الطلبات',
  ADMIN_EMAIL    : 'بريدك@gmail.com',         // ← بريد المسؤول
  SYSTEM_NAME    : 'نظام الطلبات الإلكتروني',
  ORG_NAME       : 'اسم الجهة',               // ← اسم مؤسستك
};

// ─── نقطة الدخول الرئيسية: استقبال طلبات POST ────────
function doPost(e) {
  const output = ContentService.createTextOutput();
  output.setMimeType(ContentService.MimeType.JSON);

  try {
    // [1] قراءة وتحليل البيانات الواردة
    if (!e || !e.postData || !e.postData.contents) {
      throw new Error('لم تصل بيانات صحيحة');
    }
    const data = JSON.parse(e.postData.contents);

    // [2] التحقق من الحقول الإلزامية
    validateRequiredFields(data);

    // [3] توليد رقم طلب فريد
    const requestNumber = generateRequestNumber();
    data.requestNumber  = requestNumber;

    // [4] الكتابة في Google Sheets
    writeToSheet(data);

    // [5] إرسال إيميل إشعار للمسؤول
    sendAdminNotification(data);

    // [6] إرسال تأكيد للمستخدم (إن أدخل بريده)
    if (data.email && isValidEmail(data.email)) {
      sendUserConfirmation(data);
    }

    // [7] إرجاع استجابة النجاح
    output.setContent(JSON.stringify({
      status       : 'success',
      message      : 'تم استلام طلبك بنجاح',
      requestNumber : requestNumber,
    }));

  } catch (err) {
    console.error('خطأ في معالجة الطلب:', err.message);
    output.setContent(JSON.stringify({
      status : 'error',
      message: err.message || 'حدث خطأ غير متوقع، يرجى المحاولة مرة أخرى',
    }));
  }

  return output;
}

// ─── للتحقق من أن الـ Web App يعمل (عبر GET) ──────────
function doGet(e) {
  return ContentService
    .createTextOutput(JSON.stringify({
      status : 'online',
      system : CONFIG.SYSTEM_NAME,
      time   : new Date().toLocaleString('ar-SA'),
    }))
    .setMimeType(ContentService.MimeType.JSON);
}

// ─── كتابة بيانات الطلب في Google Sheets ─────────────
function writeToSheet(data) {
  const ss    = SpreadsheetApp.openById(CONFIG.SPREADSHEET_ID);
  const sheet = ss.getSheetByName(CONFIG.SHEET_NAME);

  if (!sheet) {
    throw new Error('لم يُعثَر على الجدول: ' + CONFIG.SHEET_NAME);
  }

  const now     = new Date();
  const dateStr = Utilities.formatDate(now, 'Asia/Riyadh', 'yyyy/MM/dd');
  const timeStr = Utilities.formatDate(now, 'Asia/Riyadh', 'HH:mm:ss');

  // ترتيب الأعمدة يطابق هيكل الجدول (القسم 1.2)
  sheet.appendRow([
    data.requestNumber,   // A — رقم الطلب
    dateStr,              // B — تاريخ الإرسال
    timeStr,              // C — وقت الإرسال
    data.fullName    || '',  // D — الاسم الكامل
    data.phone       || '',  // E — رقم الهاتف
    data.email       || '',  // F — البريد الإلكتروني
    data.city        || '',  // G — المدينة / المنطقة
    data.requestType || '',  // H — نوع الطلب
    data.details     || '',  // I — تفاصيل الطلب
    'جديد',                  // J — الحالة (افتراضي)
    '',                      // K — ملاحظات المسؤول (فارغ)
    Utilities.formatDate(now, 'Asia/Riyadh', 'yyyy/MM/dd HH:mm'), // L
  ]);
}

// ─── التحقق من الحقول الإلزامية ──────────────────────
function validateRequiredFields(data) {
  const required = {
    fullName   : 'الاسم الكامل',
    phone      : 'رقم الهاتف',
    city       : 'المدينة / المنطقة',
    requestType: 'نوع الطلب',
    details    : 'تفاصيل الطلب',
  };

  for (const [field, label] of Object.entries(required)) {
    if (!data[field] || data[field].toString().trim() === '') {
      throw new Error('حقل "' + label + '" مطلوب ولا يمكن أن يكون فارغاً');
    }
  }

  if (data.details.trim().length < 10) {
    throw new Error('تفاصيل الطلب يجب أن تكون 10 أحرف على الأقل');
  }
}
```

### 2.3 Helpers.gs — الدوال المساعدة

أنشئ ملفاً جديداً باسم `Helpers.gs` والصق فيه:

```javascript
// ====================================================
// Helpers.gs — دوال مساعدة مشتركة
// ====================================================

// ─── توليد رقم طلب فريد ──────────────────────────────
// الصيغة: REQ-YYYYMMDD-XXXX (مثال: REQ-20260501-0047)
function generateRequestNumber() {
  const ss      = SpreadsheetApp.openById(CONFIG.SPREADSHEET_ID);
  const sheet   = ss.getSheetByName(CONFIG.SHEET_NAME);
  const lastRow = sheet.getLastRow(); // يشمل صف العناوين
  const seq     = String(lastRow).padStart(4, '0');
  const dateStr = Utilities.formatDate(new Date(), 'Asia/Riyadh', 'yyyyMMdd');
  return 'REQ-' + dateStr + '-' + seq;
}

// ─── التحقق من صحة البريد الإلكتروني ────────────────
function isValidEmail(email) {
  if (!email) return false;
  return /^[^\s@]+@[^\s@]+\.[^\s@]+$/.test(email.trim());
}

// ─── تأمين HTML لمنع XSS في قوالب البريد ────────────
function escapeHtml(text) {
  if (!text) return '';
  return String(text)
    .replace(/&/g,  '&amp;')
    .replace(/</g,  '&lt;')
    .replace(/>/g,  '&gt;')
    .replace(/"/g,  '&quot;')
    .replace(/'/g,  '&#39;');
}

// ─── دالة الاختبار (شغّلها يدوياً من محرر Apps Script) ─
function testConnection() {
  try {
    const ss    = SpreadsheetApp.openById(CONFIG.SPREADSHEET_ID);
    const sheet = ss.getSheetByName(CONFIG.SHEET_NAME);
    Logger.log('✅ الاتصال بـ Google Sheets يعمل بنجاح');
```

```html
function nextStep(from) {
  if (!validateStep(from)) return;
  hideGlobalError();
  currentStep = from + 1;
  if (currentStep === 3) populateReview();
  showStep(currentStep);
}

function prevStep(from) {
  hideGlobalError();
  currentStep = from - 1;
  showStep(currentStep);
}

function showStep(step) {
  document.querySelectorAll('.step-card').forEach(c => c.classList.remove('active'));
  document.getElementById('card' + step).classList.add('active');

  for (let i = 1; i <= totalSteps; i++) {
    const ind = document.getElementById('stepIndicator' + i);
    ind.classList.remove('active', 'done');
    if (i < step)   ind.classList.add('done');
    if (i === step) ind.classList.add('active');
    if (i < step)   ind.querySelector('.step-circle').textContent = '✓';
  }

  document.getElementById('progressFill').style.width =
    Math.round((step / totalSteps) * 100) + '%';
  window.scrollTo({ top: 0, behavior: 'smooth' });
}

  let valid = true;

  if (step === 1) {
    valid &= checkRequired('fullName', 'err_fullName', v => v.trim().length >= 3);
    valid &= checkRequired('phone',    'err_phone',    v => /^[0-9+\s\-]{7,15}$/.test(v.trim()));

    const email = document.getElementById('email').value.trim();
    if (email) {
      const ok = /^[^\s@]+@[^\s@]+\.[^\s@]+$/.test(email);
      markField('email', ok);
      showError('err_email', !ok);
      if (!ok) valid = false;
    } else {
      markField('email', false, true);
    }

    valid &= checkRequired('city', 'err_city', v => v.trim().length >= 2);
  }

  if (step === 2) {
    valid &= checkRequired('requestType', 'err_requestType', v => v !== '');
    valid &= checkRequired('details',     'err_details',     v => v.trim().length >= 10);
  }

  return Boolean(valid);
}

function checkRequired(id, errId, rule) {
  const val = document.getElementById(id).value;
  const ok  = rule(val);
  markField(id, ok);
  showError(errId, !ok);
  return ok;
}

}
```

## ملحق أ — دمج Gemini AI (اختياري)

أضف هذه الدالة في `Helpers.gs` لتحليل الطلبات تلقائياً بالذكاء الاصطناعي:

```javascript
/**
 * analyzeRequestWithAI
 * يُلخّص تفاصيل الطلب ويقترح الأولوية
 * مجاني ضمن حصص Gemini API اليومية
 *
 * الإعداد المسبق:
 * في Apps Script → الإعدادات → خصائص البرنامج النصي
 * أضف: GEMINI_API_KEY = مفتاحك_من_aistudio.google.com
 */
function analyzeRequestWithAI(details) {
  const key = PropertiesService.getScriptProperties()
                .getProperty('GEMINI_API_KEY');
  if (!key) return ''; // إن لم يُضبَط المفتاح، تجاهل التحليل

  const prompt =
    `أنت مساعد لمعالجة طلبات الجمهور. لخّص الطلب التالي بجملة أو جملتين
    واقترح الأولوية (عاجل / عادي / غير عاجل) بناءً على المحتوى:
    "${details}"
    أجب باللغة العربية فقط، بصيغة:
    الملخص: ...
    الأولوية: ...`;

  try {
    const resp = UrlFetchApp.fetch(
      'https://generativelanguage.googleapis.com/v1beta/models/gemini-2.0-flash:generateContent?key=' + key,
      {
        method     : 'post',
        contentType: 'application/json',
        payload    : JSON.stringify({
          contents: [{ parts: [{ text: prompt }] }]
        }),
      }
    );
    const json = JSON.parse(resp.getContentText());
    return json.candidates?.[0]?.content?.parts?.[0]?.text || '';
  } catch(err) {
    console.warn('Gemini AI error:', err.message);
    return '';
  }
}
```

**لاستخدامها:** في `Code.gs`، أضف بعد `writeToSheet(data)`:
```javascript
const aiSummary = analyzeRequestWithAI(data.details);
if (aiSummary) {
  data.aiSummary = aiSummary;
  // يمكن إضافة عمود M "تحليل AI" في الجدول
  // أو إضافتها في قسم إضافي في بريد المسؤول
}
```

## ملحق ب — رمز QR للنموذج

لإنشاء رمز QR مجاناً يوصل للنموذج مباشرة:

```
1. اذهب إلى: qr-code-generator.com
2. اختر نوع "URL"
3. الصق رابط النموذج النهائي
4. خصّص الألوان لتناسب هوية الجهة:
   - اللون الأساسي: #1565C0 (أزرق)
   - الخلفية: أبيض
5. حمّل بصيغة SVG (للطباعة) أو PNG (للشاشة)
6. الحجم المثالي للطباعة: 300×300 بكسل على الأقل
7. اطبعه على:
   □ الإعلانات الرسمية
   □ البروشورات والكتيبات
   □ لافتات المكتب / الاستقبال
   □ التوقيع الإلكتروني للبريد
```
